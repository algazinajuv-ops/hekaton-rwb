## Ветка sql-core
 
### 28.10.2026: общие вопросы по проектированию модели
- Кто: участник с веткой sql-core
- Что спросили у ИИ: как определять гранулярность таблиц, выбирать типы данных (TEXT, INTEGER, NUMERIC, TIMESTAMP), делать скрипт повторно запускаемым, почему деньги хранят в NUMERIC, как безопасно приводить текст из CSV к числам и датам
- Что он ответил (коротко): общие правила: гранулярность это смысл одной строки, деньги в NUMERIC, пустые значения через NULLIF перед приведением типов, повторный запуск через DROP ... IF EXISTS
- Как проверили: ответы сопоставлены с требованием задания, что скрипт собирает модель из raw с нуля и запускается на чистой базе
- Что изменили или решили сами: уточнить у участника sql-core
- Примечание: ответ ИИ советует CREATE SCHEMA IF NOT EXISTS, но для полной пересборки нужен DROP SCHEMA IF EXISTS core CASCADE, иначе старые таблицы остались бы. Конкретная модель (таблицы, ключи) на момент записи не прислана; запись дополнить после этого
